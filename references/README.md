Public reference repositories used for pattern selection

The following repositories were identified from public GitHub searches and cloned locally to provide realistic patterns for the architecture we are building.

- first-fluke/fullstack-starter
  - Purpose: general fullstack starter; useful for backend + frontend assembly patterns.
- giladfuchs/fullstack-template-fastapi-react-vue
  - Purpose: FastAPI + frontend template; useful for API-first product scaffolds.
- BRVWL/electron-react-typescript-template
  - Purpose: desktop app template for native windowed products.
- outflanknl/RedELK
  - Purpose: red-team / security monitoring / detection patterns.
- st0pp3r/awesome-detection-engineer
  - Purpose: detection engineering and SOC-oriented security thinking.

This is not a substitution for production code; it is a source of proven architecture patterns and a way to avoid reinventing the wheel for common product and security baselines.
